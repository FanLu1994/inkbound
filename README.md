# 墨痕 · Inkbound

一个圆珠笔手绘风格的平台跳跃游戏，单个 `index.html` 即可游玩，无需任何依赖或服务器。

直接用浏览器打开 `index.html` 开始游戏。

## 操作

| 按键 | 动作 |
|---|---|
| ← → / A D | 移动 |
| 空格 / Z / W | 跳跃（支持二段跳、蹬墙跳；↓+跳 可穿过木板） |
| Shift / X | 冲刺 |
| P / Esc | 暂停 |
| R | 重开本章 |
| M | 静音 |

触屏设备会自动显示虚拟按键。

## 特性

- 全程 Canvas 程序化绘制：抖动线条、交叉排线、横线纸底，无任何图片素材
- 三个章节，含移动平台、弹簧、尖刺、墨池、存档点、巡逻墨团与飞蛾
- 土狼时间、跳跃缓冲、可变跳高、贴墙滑行、冲刺残影、挤压拉伸等手感细节
- WebAudio 合成音效与环境音
